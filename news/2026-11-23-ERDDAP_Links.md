The ERDDAP links for the CCHDO [bottle](https://data.pmel.noaa.gov/pmel/erddap/tabledap/cchdo_bottle.html) and [CTD](https://data.pmel.noaa.gov/pmel/erddap/tabledap/cchdo_ctd.html) datasets have been updated to point to NOAA PMEL's main ERDDAP server.

Please update any existing code or workflows that reference the previous endpoints to reflect the new URLs.

Both datasets also now include a `cruise_page` variable linking to the corresponding CCHDO cruise page.
